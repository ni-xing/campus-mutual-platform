# 搭把手 · 设计方案（校园互助生活平台）

> 视觉主张：**宿舍楼下的布告栏**。校园互助的本质是「贴一张条子，有人搭把手」，整套视觉从布告栏、便利贴、图钉、方格稿纸里长出来，而不是从 SaaS 模板里套。

## 一、配色 Token

| Token | 值 | 用途 |
|---|---|---|
| `--paper` | `#FBF9F3` | 底纸白，页面基底 |
| `--grid` | `rgba(90,140,110,.14)` | 方格稿纸底纹线 |
| `--ink` | `#24418F` | 墨水蓝（主色）：按钮、链接、标签 |
| `--ink-deep` | `#1A2F6B` | 墨水蓝深，hover / 按钮投影 |
| `--highlight` | `#FFD84D` | 便利贴黄：高亮帖、失物急帖、强调 CTA |
| `--pin` | `#D9432F` | 图钉红：仅用于图钉、「急」章、价格等小元素 |
| `--charcoal` | `#2B2A24` | 炭笔黑，正文与描边 |
| `--board` | `#33544B` | 黑板绿，布告栏面板 / AI 板块反白底 |

涨跌、急缓等语义色统一走图钉红；黄色永远配炭笔黑字保证对比度。

## 二、字体方案

| 角色 | 字族 | 说明 |
|---|---|---|
| 标题 / 便签 / 手写元素 | LXGW WenKai Screen（霞鹜文楷） | 手写硬笔感，是「贴出来的条子」；CDN：jsdelivr `lxgw-wenkai-screen-webfont` |
| 正文 / 界面 | 系统黑体（PingFang SC / Microsoft YaHei / Noto Sans SC） | 长文易读，两族职责分明 |

- 字阶：Hero `clamp(36px,5.4vw,60px)`；H2 `clamp(28px,3.6vw,40px)`；正文 16px / 行高 1.75；辅助 13–14px。
- 行宽控制在 80 字符以内；文案用主动语态、口语化（按钮「贴上布告栏」→ 提交后对应「已贴上」）。

## 三、版式方案

- **Web 落地页**（`index.html`）：左对齐为主，max-width 1080px。
  1. Hero：左侧手写大标题 + 双 CTA，右侧木框黑板绿「布告栏」，钉 4 张微旋转便签（二手 / 失物·急章 / 拼车 / AI）；
  2. 炭笔黑「今日布告」滚动条；
  3. 四板块非对称网格（便签黄 / 米纸 / 蓝 / 黑板绿反白），刻意不做成同款卡片；
  4. 三步流程（真序列才编号：发帖→有人接→线下交割）；
  5. 黑板绿 CTA 区 + 页脚。
- **移动端**（`mobile.html`）三屏：首页布告流（失物帖便签黄高亮）、物品详情（楼栋信用 + 双按钮）、发布页（板块分段选择 + 「贴上布告栏」）。底部 Tab 中央凸起发布钮。
- 便签卡片元素：微旋转 ±1–2.5°、顶部图钉、胶带/描边质感；不用统一圆角+同款阴影的 SaaS 卡片套件。

## 四、动效与可访问性

- 动效只保留两处：便签「钉入」入场动画（一次编排）+ 布告滚动条；响应式动作（如确认弹层）可按需加。
- `prefers-reduced-motion` 下全部动画关闭。
- `:focus-visible` 三像素墨水蓝描边；黄色便签配炭笔黑字满足对比度。

## 五、自检记录（对照 AI 默认套路）

- ❌ 奶油底 + 衬线大标题 + 陶土色 → ✅ 方格稿纸底 + 文楷 + 墨水蓝
- ❌ 近黑底 + 荧光绿 → ✅ 黑板绿只做面板底，整页仍亮色
- ❌ SaaS 等款圆角卡片 + 同款阴影 → ✅ 便签刻意不统一（旋转/图钉/红章/异色）
- ❌ ALL-CAPS eyebrow、编号装饰 → ✅ 编号仅用于真实三步流程
- ❌ 链接尾部统一「→」、中点拼接 meta → ✅ 文案按界面口吻单独写

## 六、文件清单

- `index.html` — Web 落地页（响应式，直接浏览器打开预览）
- `mobile.html` — 移动端三屏展示页
